# 智能Web漏洞扫描系统 V1.0

一个智能体驱动的自主 Web 安全测试系统。核心是一个能在运行时自主推理、决策、执行、反思的智能体：
输入目标地址后，系统自动完成侦察、规划、执行、反思、决策的循环，最终产出漏洞清单与 PDF 报告。

## 重要声明

本系统仅限用于**已获得书面授权的**安全测试、教学与研究工作。

使用者必须在创建扫描任务前确认自己对被测目标拥有合法授权。任何未经授权的扫描、探测行为
均属违法，与本项目作者无关，全部后果由使用者自行承担。系统在创建任务时会强制勾选授权确认，
并把确认行为写入审计日志以备查证。

## 核心闭环

```
输入目标地址
  -> 侦察（端口扫描 + 指纹识别）
  -> 规划（智能体制定测试计划）
  -> 执行（调用技能与工具执行测试）
  -> 反思（智能体分析结果、判断漏洞）
  -> 决策（继续 / 调整策略 / 结束）
  -> 循环（最多 15 轮）
  -> 报告生成
```

## 技术栈

| 层 | 选型 |
| --- | --- |
| 后端 | FastAPI + SQLite + SQLAlchemy |
| 推理引擎 | 多模型可配置（DeepSeek / 智谱 / 通义 / Kimi / 自定义） |
| 前端 | Vue3 + Element Plus |
| 报告 | reportlab 生成 PDF |
| 调度 | APScheduler |

## 快速开始

1. 安装后端依赖：双击 `install.bat`
2. 复制 `.env.example` 为 `.env`，填入模型 API Key
3. 启动系统：双击 `start.bat`
4. 浏览器访问 http://127.0.0.1:5173 ，接口文档见 http://127.0.0.1:8000/docs

## 模型配置

系统不写死任何模型。所有厂商信息（API 地址、模型标识、Key）都在"配置"页里维护，
支持多套配置保存与切换，以及主控模型与顾问模型的双模型协作模式。

新增一个厂商不需要改动任何智能体代码，只需要在配置页填入厂商名、API 地址、模型标识与请求格式。

## 命名与注释约定

**命名**

- 函数：模块前缀 + 动作动词 + 对象，例如 `plan_build_strategy`、`skill_load_by_context`
- 变量：形容词 + 名词，例如 `raw_probe_result`、`compressed_context`
- 安全与技术栈术语保留英文：payload、url、http、api、token、FastAPI、SQLite
- 不用 data、result、info、temp 这类万能词

**注释**

只写"为什么"，不写"代码在干嘛"。把一行代码翻译成中文的注释一律不留。

- 函数开头写设计说明，固定三段：做什么 + 为什么这么做 + 放弃了什么
- 关键行写清楚这个值为什么是它、这个写法为什么选它、这里踩过什么坑
- 关键位置保留迭代痕迹，带日期或 TODO 署名
